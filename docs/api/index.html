API reference

Base URL and version

https://api.example-acme-telemetry.test/v1. The version is in the path and we do not remove versions.

Authentication

Bearer token in the Authorization header. Keys are scoped to one workspace and one mode, sandbox or live. A key can be read-only or read-write.

Endpoints

MethodPathWhat it does
POST/v1/eventsSend one event or a batch of up to 1,000
GET/v1/eventsQuery raw events within your retention window
GET/v1/metersList meters
POST/v1/metersCreate a meter
GET/v1/usageMetered quantities per customer per period
POST/v1/backfillsRecompute a closed period, returns a correction
GET/v1/customersList customers and entitlements

Pagination

Cursor based. Pass limit up to 1,000 and follow next_cursor until it is null. Offsets are not supported.

Idempotency

Every write takes an idempotency_key. Keys live 48 hours. Replaying a key returns the original response and changes nothing.

Timestamps

RFC 3339, always UTC. Events up to 72 hours old are attributed to their own period; older than that they are rejected with event_too_late.
