Quickstart

1. Get a key

Create a workspace, open Settings, then API keys. A sandbox key starts with sk_sandbox_ and a live key with sk_live_. Keys are shown once.

2. Send an event

curl -X POST https://api.example-acme-telemetry.test/v1/events \
  -H "Authorization: Bearer sk_sandbox_..." \
  -H "Content-Type: application/json" \
  -d '{
    "customer_id": "cus_123",
    "name": "api_call",
    "timestamp": "2026-09-30T10:00:00Z",
    "idempotency_key": "req_abc123",
    "properties": { "bytes": 2048, "endpoint": "/search" }
  }'

A 202 means accepted. Anything else is in the error reference.

3. Define a meter

In the dashboard, New meter, type Count, matching events named api_call, grouped by customer_id, period monthly. Save.

4. See the number

Open the customer. The count appears within thirty seconds. Click it to see the events behind it.

5. Move to live

Swap the sandbox key for a live one. Nothing else changes. We recommend running both for a month and comparing against your existing report before you bill from ours.
