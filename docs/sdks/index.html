SDKs

All four buffer in memory, flush every two seconds or 500 events, retry with exponential backoff, and never throw into your request path.

LanguageMinimum versionNotes
Node18ESM and CommonJS
Python3.9Sync and asyncio clients
Go1.21Context aware, no global state
Ruby3.1Thread-safe buffer

Losing events on shutdown

Call flush() before your process exits. The Node and Python clients also register a shutdown hook; Go and Ruby leave it to you deliberately, because a hook in a library is a bad neighbour.

What is not in the SDKs

No meter management and no querying. Those are dashboard, CLI, or plain HTTP — a billing pipeline should not be reconfigurable from application code.
