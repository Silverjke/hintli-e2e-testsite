CLI

Install with npm i -g @acme-telemetry/cli. Authenticate with acme login, which stores a token in your OS keychain.

Common commands

CommandWhat it does
acme meters listShow meters in the workspace
acme meters apply -f meters.yamlCreate or update meters from a file
acme usage export --period 2026-09Export metered quantities as CSV
acme backfill --meter api_calls --period 2026-08Recompute a closed period
acme events tailWatch events arrive, sandbox only

Meters as files

meters apply is declarative and safe to run from CI: it reports what would change with --dry-run and refuses to touch a meter that has an open correction.
