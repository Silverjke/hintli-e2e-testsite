Postgres

Give us a read-only role and a table or view with a timestamp column and a customer id. We poll on your schedule, minimum every five minutes.

Requirements

  • Postgres 13 or newer.
  • A monotonic column we can watermark on — a timestamp or a bigint id.
  • Network access: allowlist our egress addresses, or use the SSH tunnel.

How it behaves

We never write. We keep a watermark per source and read forward from it. A row that changes after we have read it is not picked up again, so build the view to be append-only.

Failure

If a poll fails we retry with backoff for six hours and then alert you. The watermark does not advance on a failed poll, so nothing is skipped.
