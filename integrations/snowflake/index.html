Snowflake

Same shape as Postgres: a view, a watermark column, a read-only role, and a schedule.

Setup

  1. Create a role with USAGE on the warehouse and SELECT on the view.
  2. Create a user with key-pair authentication. We do not accept passwords.
  3. Paste the account identifier, warehouse, database, schema and view into the dashboard.

Cost

Each poll is one query. On a five-minute schedule with an XS warehouse and auto-suspend at 60 seconds, customers typically see a few credits a month. Use a longer interval if that matters.

Limits

One million rows per poll. If a poll would exceed that we take the first million by watermark order and pick the rest up on the next run.
